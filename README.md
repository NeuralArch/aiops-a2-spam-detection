# AIOps Module 3 Assignment — Spam Detection API

Infrastructure & Containerization: Docker (single-stage vs. multi-stage builds, Docker
Compose with Redis caching) and Kubernetes (an Indexed Job for parallel data validation,
and a self-healing/rolling-update Deployment), built around a small TF-IDF + Naive Bayes
spam-detection REST API.

## Repository structure

```
.
├── app/
│   ├── main.py              # FastAPI app: /predict, /healthz (+ Redis caching)
│   ├── train.py              # Generates spam_dataset.csv and trains the model
│   ├── requirements.txt
│   └── model.joblib          # Trained pipeline (generated by train.py)
├── Dockerfile.naive          # Q1: single-stage build
├── Dockerfile.multistage     # Q1: multi-stage build
├── docker-compose.yml        # Q2: api + Redis cache services
├── shards/
│   ├── generate_shards.py    # Generates 8 synthetic signup-record CSV shards
│   ├── validate_shard.py     # Runs inside each Job pod; validates one shard
│   └── Dockerfile.validator  # Image for the Indexed Job
├── k8s/
│   ├── job-validate-shards.yaml   # Q3: Indexed Job
│   ├── deployment.yaml            # Q4: Deployment (2 replicas)
│   └── service.yaml               # Q4: Service (NodePort)
├── evidence/
│   ├── q1_1.png, q1_2.png, q1_3.png   # Image sizes, container run/test
```

## Running it locally

### 1. Train the model
```bash
cd app
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python3 train.py
```

### 2. Q1 — Docker builds
```bash
docker build -f Dockerfile.naive -t spam-api:naive .
docker build -f Dockerfile.multistage -t spam-api:multistage .
docker images | grep spam-api
```

### 3. Q2 — Compose (API + Redis)
```bash
docker compose up -d --build
curl http://127.0.0.1:8000/healthz
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" \
  -d '{"text":"WIN a FREE iPhone now"}'
```

### 4. Q3 — Kubernetes Indexed Job
```bash
cd shards && python3 generate_shards.py
eval $(minikube docker-env) 2>/dev/null  # or: minikube image load shard-validator:latest
docker build -f Dockerfile.validator -t shard-validator:latest .
minikube image load shard-validator:latest
kubectl apply -f ../k8s/job-validate-shards.yaml
kubectl get pods -o wide
```

### 5. Q4 — Kubernetes Deployment
```bash
minikube image load spam-api:multistage
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml
kubectl get pods -l app=spam-api -o wide
```
